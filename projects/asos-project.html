Portfolio / ASOS

ASOS

User Interface Developer

ASOS engaged me to develop its online Lookbook application, a digital platform used by buyers, fashion journalists and industry professionals to preview upcoming collections. The project focused on delivering a rich, visually engaging experience that functioned consistently across browsers, platforms and emerging tablet devices.

Project Details

Client / Organisation
ASOS
Date
September 2011 – November 2011
Role
User Interface Developer
Project Focus
Digital fashion publishing, online lookbook development, responsive user interfaces and cross-platform compatibility.
Technical Environment
HTML5, CSS3, JavaScript, jQuery, AJAX, Responsive Design and Front-End Development.

Project Focus

The project centred on the creation of a digital Lookbook application designed to showcase upcoming fashion collections to trade buyers, media organisations and fashion industry professionals. The platform needed to present high-quality visual content in an engaging and accessible manner while maintaining the premium brand experience expected from one of the UK's leading online fashion retailers.

Particular attention was given to ensuring that the application worked consistently across multiple browsers and devices, including tablets, which were becoming increasingly important within the fashion industry for reviewing collections and sharing visual content.

My Contribution

Working as part of the ASOS digital team, I was responsible for the front-end implementation of the Lookbook application, translating design concepts into functional user interfaces that supported the presentation of rich visual content while maintaining performance and usability.

Main contributions included:

  • Front-end HTML5 and CSS3 development
  • User interface implementation and styling
  • JavaScript and jQuery functionality development
  • Fashion lookbook presentation and navigation
  • Cross-browser compatibility improvements
  • Tablet and cross-platform optimisation
  • Rich media and visual content presentation
  • User experience refinement and usability improvements
  • Collaboration with designers and stakeholders
  • Front-end testing and quality assurance

Technical Environment

The application was developed using HTML5, CSS3, JavaScript, jQuery and AJAX technologies to deliver a rich and interactive browsing experience. Responsive design principles and cross-platform testing ensured that the platform functioned effectively across desktop browsers and tablet devices, supporting the needs of both internal stakeholders and external fashion industry users.

Project Outcome

The completed Lookbook application provided ASOS with an effective digital platform for presenting upcoming fashion collections to trade and media audiences. Through strong front-end implementation, cross-device compatibility and careful attention to visual presentation, the project delivered a user experience aligned with the brand's position as a leading online fashion retailer.
