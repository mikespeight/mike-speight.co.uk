BBC My Web My Way

Client-Side Developer & Technical Consultant

Working within the BBC's Future Media & Technology division, I contributed to the development of My Web My Way, an award-winning accessibility initiative designed to help users adapt computers, browsers and websites to suit a wide range of disabilities and accessibility requirements.

Project Details

Client / Organisation
BBC Future Media & Technology
Date
October 2010 – September 2011
Role
Client-Side Developer & Technical Consultant
Project Focus
Digital accessibility, inclusive design, user experience enhancement and client-side application development.
Technical Environment
XHTML, CSS, JavaScript, jQuery, JSON, AJAX and Accessibility Technologies.

Project Focus

The project focused on improving digital accessibility by providing users with practical guidance on adapting their online experience according to their specific accessibility needs. The platform helped users identify suitable browser, operating system and assistive technology settings based on individual requirements, enabling a more inclusive and accessible web experience.

A key objective was to enhance the site's interactive functionality while ensuring that accessibility remained central to every aspect of the user experience. The work involved developing intelligent client-side functionality capable of dynamically tailoring content and recommendations according to user selections.

My Contribution

As Client-Side Developer and Technical Consultant, I worked within the BBC's accessibility team to design and implement a range of interactive features that improved usability and personalisation. My role combined front-end development, accessibility expertise and technical consultancy to support one of the BBC's flagship accessibility initiatives.

Main contributions included:

  • Development of accessibility-focused user interfaces
  • Object-oriented JavaScript development
  • Dynamic content personalisation based on user requirements
  • Migration of legacy JavaScript functionality to jQuery
  • Enhancement of browser and accessibility configuration tools
  • Development of client-side search functionality
  • Social media sharing feature implementation
  • User experience and accessibility improvements
  • Collaboration with accessibility specialists and stakeholders
  • Cross-browser compatibility and quality assurance

Technical Environment

The platform was built using XHTML, CSS, JavaScript, jQuery, JSON and AJAX technologies. A significant part of the work involved modernising existing client-side functionality, including the migration of legacy BBC Glow JavaScript components to jQuery, while maintaining the high accessibility standards required by the project.

Project Outcome

The project contributed to the continued success of My Web My Way as one of the BBC's most important accessibility initiatives. Through improved personalisation, enhanced usability and modernised client-side functionality, the platform helped users with a wide range of accessibility needs access practical guidance for creating a more inclusive and effective online experience.
