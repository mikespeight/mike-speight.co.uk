Portfolio / HH Global

HH Global

UX/UI Consultant, User Experience Developer & Agile Coach

HH Global engaged me to help enhance a print management and marketing procurement platform, providing UX consultancy, front-end development expertise and Agile coaching. The assignment combined enterprise application development with user experience improvements and support for Agile delivery practices.

Project Details

Client / Organisation
HH Global
Date
November 2011 – July 2012
Role
UX/UI Consultant, User Experience Developer & Agile Coach
Project Focus
Enterprise application development, print management workflows, user experience optimisation and Agile adoption.
Technical Environment
HTML5, CSS3, JavaScript, jQuery, AJAX, Agile Delivery and Enterprise Application Development.

Project Focus

The project focused on the continued development and enhancement of a sophisticated print management and procurement platform used by global organisations to manage marketing production, print procurement and related business processes. The application supported complex workflows involving multiple stakeholders, suppliers and approval processes.

A key objective was to improve the usability of the platform while ensuring that increasingly sophisticated functionality remained intuitive and efficient for users. Alongside the technical work, the organisation was also interested in adopting more Agile ways of working, creating an opportunity to combine UX expertise with Agile coaching and delivery support.

My Contribution

Working closely with business stakeholders, developers and project management teams, I contributed to both the evolution of the platform and the adoption of Agile delivery practices. My role combined user experience consultancy, front-end implementation and mentoring activities aimed at improving collaboration and delivery effectiveness.

Main contributions included:

  • UX architecture and interface design
  • User workflow analysis and optimisation
  • Front-end HTML, CSS and JavaScript development
  • Enterprise application usability improvements
  • Information architecture and interaction design
  • Agile coaching and Scrum guidance
  • Support for Agile adoption and process improvement
  • Stakeholder collaboration and requirements analysis
  • Cross-browser compatibility and quality assurance
  • Front-end standards and best practice implementation

Technical Environment

The platform was developed using HTML, CSS, JavaScript, jQuery and AJAX technologies to deliver a rich browser-based enterprise application experience. The work was undertaken within an evolving Agile environment, where I provided guidance and practical support to teams adopting Agile and Scrum delivery practices.

Project Outcome

The engagement contributed to the ongoing improvement of HH Global's print management platform through enhanced usability, improved user workflows and stronger front-end implementation. By combining UX consultancy with Agile coaching, the project also helped support the organisation's move towards more collaborative and iterative delivery practices, benefiting both users and development teams.
