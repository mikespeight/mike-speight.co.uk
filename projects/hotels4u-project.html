Portfolio / Hotels4U

Hotels4U

Senior UI Consultant & UX Architect

Hotels4U, part of the Thomas Cook Group, engaged me to help deliver the front-end architecture and responsive user experience for a new hotel search and booking platform. The project focused on creating a seamless travel booking experience across a wide range of devices and screen sizes.

Project Details

Client / Organisation
Hotels4U / Thomas Cook Group
Date
March 2014 – September 2014
Role
Senior UI Consultant & UX Architect
Project Focus
Responsive e-commerce, travel booking user experience and front-end architecture.
Technical Environment
HTML5, CSS3, JavaScript, jQuery, Angular, AJAX, LESS, Bootstrap 3, Grunt and Jasmine.

Project Focus

The project centred on the development of a new responsive travel booking platform that enabled customers to search, compare and book hotels through a modern and intuitive user interface. At a time when responsive design was becoming increasingly important, the challenge was to provide a consistent and effective experience across devices ranging from smartphones to large desktop displays.

Particular attention was given to search functionality, booking journeys and the presentation of large volumes of travel information. The platform also required different functionality and interface behaviours depending on the device being used, ensuring that users could efficiently complete their travel research and booking tasks regardless of how they accessed the site.

My Contribution

As Senior UI Consultant and UX Architect, I was responsible for the design and implementation of the front-end user interface, working closely with business stakeholders, designers and developers to deliver a responsive travel booking experience that balanced usability, performance and commercial objectives.

Main contributions included:

  • UX architecture and customer journey optimisation
  • Responsive front-end development
  • Design and implementation of page layouts and styling
  • Mobile-first and responsive design techniques
  • Search and booking workflow enhancement
  • Device-specific interface behaviours and functionality
  • HTML5, CSS3 and JavaScript implementation
  • Collaboration with designers and backend developers
  • Cross-browser and cross-device compatibility testing
  • Front-end quality assurance and best practice guidance

Technical Environment

The platform was built using HTML5, CSS3, JavaScript, jQuery and Angular, supported by AJAX-driven interactions and responsive design techniques. LESS, Bootstrap 3, Grunt and Jasmine were used to support efficient development, testing and deployment processes within an Agile delivery environment.

Project Outcome

The project delivered a modern responsive booking platform that enabled customers to research and book travel services effectively across desktop, tablet and mobile devices. Through a combination of strong UX principles, responsive design and robust front-end implementation, the platform supported Hotels4U's objective of providing a competitive and user-friendly online booking experience within the highly competitive travel sector.
