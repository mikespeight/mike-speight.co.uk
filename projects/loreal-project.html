Portfolio / L'Oréal Studio Line

L'Oréal Studio Line

Senior UI Consultant & UX Architect

Working with The Rumpus Room on behalf of L'Oréal, I helped deliver an interactive digital campaign for the Studio Line #TXT product range. The project combined responsive web technologies, user-generated content and social media integration to create an engaging brand experience across multiple devices.

Project Details

Client / Organisation
L'Oréal (via The Rumpus Room)
Date
August 2013 – September 2013
Role
Senior UI Consultant & UX Architect
Project Focus
Interactive digital campaign, user-generated content, responsive design and social media engagement.
Technical Environment
HTML5, CSS3, JavaScript, jQuery, HTML5 Video, Modernizr, AJAX, LESS and Responsive Design.

Project Focus

The project centred on the creation of an interactive digital campaign that encouraged users to create and share personalised videos featuring L'Oréal Studio Line products. Users could upload photographs and video clips, combine them with pre-produced campaign assets and generate customised promotional content that could be shared through social media channels.

A key challenge was ensuring that the application delivered a consistent experience across a wide range of devices while supporting rich media functionality and interactive user participation. The platform needed to balance creativity, usability and performance whilst maintaining strong alignment with the Studio Line brand.

My Contribution

As Senior UI Consultant and UX Architect, I was responsible for the responsive front-end implementation and user experience design of the application. Working closely with designers, creative teams and developers, I translated campaign concepts into a functional and engaging digital experience that supported user interaction and content creation.

Main contributions included:

  • UX architecture and interaction design
  • Responsive front-end development
  • HTML5 and CSS3 implementation
  • Interactive media and video integration
  • User-generated content workflows
  • Cross-device and cross-browser compatibility
  • Social media sharing functionality
  • Performance and usability optimisation
  • Collaboration with creative and technical teams
  • Front-end quality assurance and testing

Technical Environment

The application utilised HTML5, CSS3, JavaScript and jQuery together with HTML5 Video and AJAX technologies to deliver a rich interactive experience. Modernizr and LESS supported responsive implementation and cross-device compatibility, enabling the campaign to function effectively across desktop, tablet and mobile platforms.

Project Outcome

The completed campaign successfully combined interactive content creation, social media engagement and responsive design to deliver an immersive brand experience for L'Oréal Studio Line. The project demonstrated how modern web technologies could be used to create engaging marketing experiences that encouraged participation, content sharing and increased brand interaction.
