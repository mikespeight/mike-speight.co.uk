Portfolio / Pearson

Pearson

Senior UI Consultant & UX Architect

Pearson engaged me to work on a number of enterprise content management and publishing initiatives, including the development of a Global Content Authoring System and the CHORUS extranet platform. The assignment focused on creating intuitive interfaces for complex content creation, management and publishing workflows.

Project Details

Client / Organisation
Pearson
Date
October 2013 – March 2014
Role
Senior UI Consultant & UX Architect
Project Focus
Enterprise content management, digital publishing workflows, user experience design and front-end architecture.
Technical Environment
HTML5, CSS3, JavaScript, jQuery, Underscore, AJAX, SASS, Bootstrap, XML, XSLT and XOPUS.

Project Focus

The project focused on the development of enterprise content management and publishing systems used by authors, editors and content teams across a global organisation. A key component of the work involved creating user interfaces that enabled complex content structures to be authored, managed and published efficiently while maintaining a positive user experience.

Particular emphasis was placed on simplifying sophisticated workflows and presenting technical publishing functionality in an accessible and intuitive manner. The systems supported the creation and management of structured content that could be reused and published across multiple channels and formats.

My Contribution

As Senior UI Consultant and UX Architect, I was responsible for the design and implementation of user interfaces supporting a range of enterprise publishing applications. Working closely with business stakeholders, architects and development teams, I translated complex technical requirements into intuitive user experiences that improved usability and productivity.

Main contributions included:

  • UX architecture and interface design
  • Front-end development for enterprise applications
  • User workflow analysis and optimisation
  • Development of the Global Content Authoring System user interface
  • User interface implementation for the CHORUS extranet platform
  • Information architecture and content modelling support
  • HTML5, CSS3 and JavaScript development
  • XML publishing workflow visualisation
  • Collaboration with business and technical stakeholders
  • Cross-browser testing and quality assurance

Technical Environment

The solution utilised HTML5, CSS3, JavaScript, jQuery and Underscore to deliver rich user interfaces for enterprise publishing systems. XML, XSLT and the XOPUS XML editor formed key parts of the publishing architecture, while SASS, Bootstrap and AJAX technologies supported efficient front-end development and interaction design.

Project Outcome

The project delivered user-friendly interfaces for complex content management and publishing environments, helping authors and content teams create, organise and manage content more effectively. Through the application of UX principles and modern front-end techniques, the resulting solutions improved usability while supporting Pearson's wider content publishing and knowledge management objectives.
